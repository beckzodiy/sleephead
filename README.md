# Sleepyhead

Telegram Mini App that helps you fall asleep. Red-on-black UI with no blue light, no clock and no streaks.

- **Brain dump** – write tomorrow's to-dos so they stop looping in your head
- **Breathe** – slow 6/min pacer (plus 4-7-8 and box), haptics and tones, screen goes dark
- **Shuffle** – a calm voice says a random harmless word every 8 s
- **Sounds** – brown, pink, rain or drone with a slow fade-out
- **Can't sleep** – suggests getting up instead of lying awake on your phone

Single file: `index.html`. Hosted on GitHub Pages at https://sleepy.beckzodiy.com
